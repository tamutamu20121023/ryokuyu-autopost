# 会議録テンプレート

このファイルをコピーして `inbox/` に置き、`[ ]` の中を実際の内容に置き換えてください。
AIが「会議録 → 活動ブログ記事」に整えます。書かなかった項目は記事に使われません。

```markdown
---
title: 【後期役員会】第◯回 緑友会議
subtitle: ◯/◯ 公約の進捗について話し合いました
category: 会議
date: 2026-◯◯-◯◯
promise_ids:
---

◯月◯日に役員会室で第◯回緑友会議を行いました。
今回は後期の公約の進捗について話し合いました。

### 話し合ったこと

- [公約名] について、[議論した内容]
- [公約名] について、[議論した内容]
- [その他の議題]

### 出た意見

- [賛成・慎重・保留などの意見]
- [課題として挙がったこと]

### 決まったこと

- [次にやること]
- [担当・期限が決まっていれば書く]

### 次回

◯月◯日（◯）に開催予定です。
```

## 書き方のコツ

- **数字・日付・名前は正確に**書く（AIは書かれていない事実を作りません）
- 公約について話した場合は、公約名をそのまま書く（AIが `promise_ids` を自動で紐づけます）
- 生徒の氏名は書かない（役職・学年まで）
- 「決まったこと」と「まだ議論中のこと」を分けて書く

## 公約IDを確認する

```powershell
node src/cli.mjs promises
```

## 生成して公開する

```powershell
node src/cli.mjs generate --file inbox/会議録_2026-11-05.md
# プレビューを確認
node src/cli.mjs publish drafts/2026-11-05-act-xxxx.json --yes
```
